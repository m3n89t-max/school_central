# Claude Code 보유 스킬 · 에이전트 목록

이 세션에서 쓸 수 있는 스킬과 서브에이전트를 정리한 참조 문서다(2026-08-31 기준).

> **중요**: 이 스킬들은 Claude Code에 **내장**돼 있다. `~/.claude/skills`나 프로젝트 `.claude/skills`에 파일로 존재하지 않으므로 복사·이동할 수 없다. 이 문서는 "무엇이 있고 언제 쓰는지"를 적어둔 목록일 뿐, 스킬 자체가 아니다.
>
> 직접 만든 스킬을 추가하려면 `.claude/skills/<이름>/SKILL.md`를 만들면 된다(현재 이 프로젝트에는 없음).

## 스킬 (`/이름`으로 호출)

### 개발 · 코드 품질

| 스킬 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `/code-review` | 현재 변경분·PR·브랜치를 검토해 버그와 정리거리를 찾는다. 레벨(low~max)로 깊이 조절 | 커밋·PR 전 점검 |
| `/simplify` | 변경된 코드의 중복·복잡도·비효율을 찾아 **고쳐준다**. 버그는 안 찾음 | 동작은 되는데 코드가 지저분할 때 |
| `/security-review` | 현재 브랜치 변경분의 보안 검토 | 외부 입력·인증·권한 코드를 건드렸을 때 |
| `/run` | 이 프로젝트 앱을 실제로 띄워서 동작을 확인한다 | "정말 되는지" 눈으로 봐야 할 때 |
| `/init` | 코드베이스를 분석해 CLAUDE.md 초안을 만든다 | 새 프로젝트 시작 시 |

### 시각화 · 산출물

| 스킬 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `/dataviz` | 차트·그래프·대시보드를 만들 때의 색·형태·접근성 규칙 | **모든** 차트 작업 전 필수 |
| `/design` | 여러 아트보드를 한 캔버스에 올린 시각 디자인. 화면 목업, 랜딩페이지, 포스터 등 | 손으로 다듬고 싶은 디자인 시안 |
| `/artifact-design` | 공유 가능한 웹페이지(Artifact) 제작 시 디자인 기준 | Artifact 발행 전 필수 |
| `/artifact-diagramming` | Artifact 안에 다이어그램을 그릴 때 | 구조·흐름을 그림으로 설명할 때 |
| `/artifact-capabilities` | Artifact에 실시간 데이터·저장·다중 사용자 상태 같은 기능을 넣을 때 | 정적 HTML로 안 되는 페이지 |

### 자동화 · 환경설정

| 스킬 | 하는 일 | 언제 쓰나 |
| --- | --- | --- |
| `/loop` | 프롬프트나 슬래시 명령을 주기적으로 반복 실행 | "5분마다 배포 상태 확인" 같은 폴링 |
| `/schedule` | cron으로 도는 클라우드 에이전트(루틴) 생성·관리 | 정기 작업, 1회성 예약 실행 |

| `/fewer-permission-prompts` | 자주 쓰는 읽기 전용 명령을 허용목록에 추가해 권한 확인창을 줄인다 | 승인 팝업이 잦을 때 |
| `/keybindings-help` | 단축키 커스터마이징 | 키 바인딩 변경 |

## 서브에이전트 (병렬 작업용)

사용자가 명시적으로 요청할 때만 띄운다. 각 에이전트는 문맥 없이 새로 시작하므로, 그냥 처리할 수 있는 일은 직접 하는 편이 빠르다.

| 에이전트 | 용도 |
| --- | --- |
| `Explore` | 넓은 범위를 훑어 파일·코드 위치를 찾는 읽기 전용 검색 |
| `Plan` | 구현 전략·단계별 계획 수립 |
| `general-purpose` | 다단계 조사·검색·실행 |
| `claude-code-guide` | Claude Code / Agent SDK / Claude API 사용법 질문 |
| `statusline-setup` | 상태줄 설정 |
| `claude` | 위에 안 맞는 나머지 전부 |

## 별도 명령

| 명령 | 설명 |
| --- | --- |
| `/code-review ultra` | 클라우드에서 도는 다중 에이전트 심층 리뷰. **사용자가 직접 실행해야 하고 과금됨** — 제가 대신 띄울 수 없다 |
| `/artifacts` | 발행한 Artifact 목록 (터미널) |
| `/model`, `/fast`, `/config` | 모델 전환, 고속 모드, 설정 |

## 이 프로젝트에서 실제로 쓸 만한 것

- **`/code-review`** — Phase 2에서 데이터 수집 로직을 붙일 때
- **`/dataviz`** — 6.2 실외 대기질 연동에서 권역별 농도 그라데이션을 그릴 때
- **`/claude-api`** — 6.1 AI 이상징후 멘트, 6.3 AI 보고서 착수 시 모델 선택·비용 산정
- **`/run`** — 로컬에서 앱 띄워 확인
- **`/update-config`** — 커밋 전 자동 타입체크 같은 훅이 필요해지면
